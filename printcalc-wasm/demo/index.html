printcalc-wasm demo

Mirrors printcalc_lib's root API in the browser: parse_slice_bytes, parse_job, new_job, calculate, plus the calc_job one-shot (TOML in, breakdown out) and the built-in preset listings. Nothing here touches a filesystem or a profile library — everything is bytes/strings in, JSON out.

1. Parse a sliced file

Pick any supported sliced file (.gcode, .bgcode, .gcode.3mf, .sl1, .sl1s).

(pick a file)

2. Calc a Bundled-tier job

Must be Bundled tier (embedded profiles + embedded slice summary) — there's no filesystem here to resolve a ref = or re-parse a path = against. Testfiles/bundled-job-example.toml in the repo root is a ready-made example. 

(pick a job .toml)
